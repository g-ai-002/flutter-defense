# 萝卜保卫战 🥕

基于 Flutter + Flame 的中国风单机塔防，支持 Android、Windows 与 Web。建造弓弩、火炮、冰霜、雷电与毒液防御塔，沿着弯曲的土路拦截怪物，守住终点的大萝卜；11 个关卡里还有直线飞越土路的蝠妖与持续腐蚀的毒雾，通关后可以挑战波次无尽、本地排行的高难模式。

## 功能

- 🗺️ **11 个手写关卡**：草原、森林、沙漠、雪原、熔岩、月夜 6 套地貌，S 弯、折返、蛇形等不同路线
- ☠️ **毒雾地形**：绿色毒雾区按最大生命值比例持续腐蚀地面敌人，无视护甲，可用于削弱强敌
- 🏹 **5 类防御塔 × 3 级**：弓弩塔单体速射、火炮塔范围轰击、冰霜塔减速、雷电塔连锁、毒液塔持续中毒；支持升级、出售与射程预览
- ♾️ **无尽挑战**：120 波程序化波次，怪物逐波解锁、血量二次增长，每 15 波出现首领；按坚守波数结算称号，本地排行榜保留前 10 条
- 👾 **6 类敌人**：萝卜怪、疾风兔、铁甲虫、岩甲兽、魔王首领与蝠妖，各自拥有速度、护甲与赏金差异
- 🦇 **蝠妖**：从入口沿直线飞向萝卜，不走土路，且免疫减速与中毒，逼你重新规划火力覆盖
- 🌊 **波次系统**：准备倒计时自动开波，提前出击获得额外金币，清理波次领取奖励
- ⭐ **星级与解锁**：按萝卜剩余血量评星，通关解锁下一关，最佳星级本地保存
- ⏩ **战斗节奏**：1x / 2x / 3x 倍速，30 / 60 / 120Hz 逻辑刷新率可调，默认 60Hz
- 🎨 **全程序化美术**：地貌装饰、土路、萝卜、塔、怪物、弹道、爆炸与飘字全部 Canvas 绘制，仓库无图片
- 🎵 **运行时合成音频**：15 种音效与 16 秒五声音阶循环 BGM，通过 flutter_soloud 播放，仓库无音频文件
- 🖥️ **自适应界面**：手机 / 折叠屏 / 平板 / Windows 窗口自适应，窄屏自动横屏全屏，竖屏与超窄屏下塔栏可横向滚动，HUD 悬浮不挤占战场
- ⚡ **流畅度优化**：地貌、塔身、萝卜与弹道整图缓存，敌人路径游标采样，起点光圈与投影免实时模糊，HUD 按需刷新、暂停停帧、音频后台合成
- 🌓 深色模式、简体中文、Windows 优先 `Microsoft YaHei UI`，Web 使用 soup_fonts 思源黑体
- 🧾 日志按天写入用户目录，设置页可查看最近日志
- 🔒 完全本地运行，不包含任何联网功能

## 玩法

1. 在准备阶段点击下方塔栏选择防御塔，再点击草地上的石台建造；也可先点石台再选塔。
2. 点击已建好的塔查看射程，可升级或出售（返还 70% 投入）。
3. 提前点击「开始第 N 波」可以获得额外金币，准备倒计时结束也会自动开波。
4. 怪物走到终点会扣减萝卜血量，血量归零即失败；撑过全部波次即通关。
5. 萝卜剩余血量越多星级越高：满血三星，剩余 ≥50% 两星，其余一星。
6. 首页「无尽挑战」使用最长路线，波次无限递增；失败后按坚守波数记录成绩，可在首页奖杯按钮查看本地排行榜。

小技巧：冰霜塔的减速能让火炮塔的范围伤害打满；雷电塔适合放在怪物密集的拐角；毒液塔的中毒无视护甲，适合对付铁甲虫、岩甲兽与首领；弓弩塔性价比高，适合前期铺场。蝠妖只走直线，记得在入口到萝卜的连线上也留几座塔；毒雾区会持续削弱路过的地面怪物，把火力架在毒雾边缘更划算。

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 GitHub Actions / Gitea Actions 里手动运行 `build` 工作流，选中 `v*` Tag 时按该 Tag 的版本构建 Android / Windows / Web 并发布 Release；运行 `main` 则产出预览产物。音频运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件。

## 日志位置

- Windows：`文档/CarrotDefense/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `CarrotDefense/logs/`
- Web：仅保留内存日志，可在设置页查看

## 目录结构

```
lib/
├── game/       战斗引擎、数值平衡、路径、关卡数据、固定步长时钟
├── flame/      Flame 游戏入口、战场组件、程序化美术绘制
├── pages/      首页、选关、对局、设置及悬浮 HUD / 结算组件
├── services/   日志、偏好存储、文件系统、音效与音乐、音频合成
├── providers/  设置与关卡进度状态
├── models/     塔 / 敌人 / 关卡 / 波次模型
├── theme/      应用主题与地貌配色
└── utils/      常量、布局、窗口与横屏控制、格式化
```
